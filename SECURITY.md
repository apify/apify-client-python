# Security Policy

## Supported Versions

| Version       | Status                                                            |
| ------------- | ----------------------------------------------------------------- |
| 3.x           | Supported, bug fixes and security fixes land in the latest minor  |
| 2.x           | Security fixes only (high and critical severity) until 2027-05-20 |
| 1.x and older | End of life                                                       |

The latest major version receives all fixes, always in its latest minor release. The previous major version receives fixes for high and critical severity vulnerabilities for 12 months after the release of the next major, and reaches end of life after that. Versions past their end of life receive no fixes of any kind, so please upgrade.

## Reporting a Vulnerability

Please do not create a public issue. Report the vulnerability privately via [GitHub security advisories](https://github.com/apify/apify-client-python/security/advisories/new) instead.
