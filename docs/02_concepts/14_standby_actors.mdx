An Actor in [Standby mode](https://docs.apify.com/platform/actors/running/standby) runs a web server that you call over HTTP. To send it a request, use <ApiLink to="class/ActorClient#standby_request">`ActorClient.standby_request`</ApiLink> with a path on the Actor's server:

The client looks up the Actor's Standby URL and authenticates the request with your API token. For how the platform handles the token, see [How do I authenticate my requests](https://docs.apify.com/platform/actors/running/standby#how-do-i-authenticate-my-requests).

The first request to an idle Actor can take a few minutes, so the method uses the `long` [timeout](./11_timeouts.mdx) tier. Server errors and rate-limit responses are [retried](./05_retries.mdx), so an endpoint that isn't safe to call twice may get the same request more than once.
